## **Token (LLM) = Token (ERC20)**

대규모 언어 모델(LLM) API 호출 시 소비되는 Token은 블록체인상의 ERC20 Token 가치로 변환됩니다.

---

### 🌟 비전 & 미션

**LLM API Share Network**는 **0G Chain**을 기반으로 구축된 탈중앙화 LLM API Token 공유 네트워크입니다. 우리의 미션은 지정학적 장벽과 금융 결제 제한을 타파하고, Web3 기술을 통해 글로벌 AI 리소스의 자유로운 유통, 저마찰 결제 및 가치 공유를 실현하는 것입니다.

### 📈 시장 기회

AI 기술의 폭발적인 성장과 함께 글로벌 LLM 시장은 2033년까지 **$82B+**에 달할 것으로 예상됩니다. 하지만 지정학적 및 금융 정책의 제한으로 인해 전 세계 **1,100만 명** 이상의 잠재적 사용자(개발자, 기업, 크리에이터)가 AI 서비스 단절, 국경 간 결제 어려움 등의 과제에 직면해 있습니다. 우리는 이러한 시장의 공백을 메우는 데 주력하고 있습니다.

### ⚙️ 작동 방식

본 프로젝트는 **공급자(Provider)**와 **수요자(Consumer)**를 연결하여 효율적인 AI 리소스 중계 네트워크를 구축합니다.

1.  **공급자 (Provider)**: 소유한 LLM API 쿼터(Claude, GPT, Gemini, DeepSeek 등)를 공유하고 Provider 노드를 운영합니다.
2.  **수요자 (Consumer)**: ShareToken (SHARE)을 사용하여 API 호출 비용을 지불합니다.
3.  **P2P Network**: 요청은 탈중앙화 P2P 네트워크를 통해 라우팅되어 효율적이고 안정적인 전달을 보장합니다.
4.  **실시간 결제**: 스마트 컨트랙트가 실제 LLM Token 소비량에 따라 실시간으로 SHARE 토큰을 민팅(발행)하고 분배합니다.

### 🪙 토큰 이코노믹스: ShareToken (SHARE)

SHARE는 네트워크의 핵심이며 혁신적인 **동적 발행 모델**을 채택하고 있습니다.

-   **발행 메커니즘**: 인위적인 상한선 없이 네트워크의 실제 API 호출량에 따라 발행됩니다.
-   **분배 비율**:
    -   **85%**: 리소스를 공유하는 보상으로 공급자(Provider)에게 분배.
    -   **10%**: 생태계 발전 및 장기 운영을 위한 프로토콜 국고(Treasury)로 귀속.
    -   **5%**: 거래 유동성 확보를 위한 유동성 인센티브.
-   **핵심 로직**: 소비가 민팅을 트리거하며 가치와 사용량이 깊게 결합됩니다.

### 🏗️ 기술 아키텍처

고성능과 저비용을 실현하기 위해 **0G Chain** 생태계와 깊이 통합되어 있습니다.

-   **0G Chain**: 11,000 TPS와 서브초 파이널리티를 제공하여 고빈도 API 결제를 강력하게 지원합니다.
-   **0G Storage**: API 호출 로그를 탈중앙화 저장소에 저장합니다. 기존 클라우드 서비스 대비 비용을 95% 절감합니다.
-   **P2P Network**: libp2p를 기반으로 구축된 견고한 중계 네트워크입니다.
-   **Provider Node**: 멀티 플랫폼을 지원하는 경량 클라이언트입니다. 원클릭으로 쿼터 공유가 가능합니다.
