## **Token（LLM）= Token（ERC20）**

大規模言語モデル（LLM）の API 呼び出しで消費される Token は、ブロックチェーン上の ERC20 Token 価値へと変換されます。

---

### 🌟 ビジョン＆ミッション

**LLM API Share Network** は、**0G Chain** 上に構築された分散型 LLM API Token 共有ネットワークです。私たちのミッションは、地政学的な障壁や金融決済の制限を打破し、Web3 テクノロジーを通じてグローバルな AI リソースの自由な流通、低摩擦な決済、そして価値の共有を実現することです。

### 📈 市場機会

AI テクノロジーの爆発的な成長に伴い、世界の LLM 市場は 2033 年までに **820 億ドル（$82B+）** 以上に達すると予測されています。しかし、地政学や金融政策の制限により、世界中で **1,100 万人** 以上の潜在的なユーザー（開発者、企業、クリエイター）が、AI サービスの分断やクロスボーダー決済の困難といった課題に直面しています。私たちは、この市場の空白を埋めることに注力しています。

### ⚙️ 仕組み

当プロジェクトは、**供給者（Provider）** と **需要者（Consumer）** を結びつけ、効率的な AI リソースの中継ネットワークを構築します。

1.  **供給者 (Provider)**: 所有する LLM API クォータ（Claude, GPT, Gemini, DeepSeek など）を共有し、Provider ノードを運用します。
2.  **需要者 (Consumer)**: ShareToken (SHARE) を使用して API 呼び出しの支払いを行います。
3.  **P2P ネットワーク**: リクエストは分散型 P2P ネットワークを介してルーティングされ、効率的で安定した転送を保証します。
4.  **リアルタイム決済**: スマートコントラクトが実際の LLM Token 消費量に基づき、リアルタイムで SHARE トークンをミント（鋳造）し分配します。

### 🪙 トークンエコノミクス：ShareToken (SHARE)

SHARE はネットワークの核となるトークンであり、革新的な**動的発行モデル**を採用しています。

-   **発行メカニズム**: 発行上限は設けず、ネットワークの実際の API 利用量に完全に連動して発行されます。
-   **分配比率**:
    -   **85%**: リソースを共有する報酬として供給者（Provider）に分配。
    -   **10%**: エコシステムの発展と長期運用のためのプロトコル・トレジャリー（国庫）へ。
    -   **5%**: 取引の厚みを確保するための流動性インセンティブ。
-   **コアロジック**: 消費がミントをトリガーし、価値と利用量が深く結びつきます。

### 🏗️ 技術アーキテクチャ

高性能かつ低コストを実現するため、**0G Chain** エコシステムと深く統合されています。

-   **0G Chain**: 11,000 TPS とサブ秒単位のファイナリティを提供し、高頻度な API 決済を強力にサポート。
-   **0G Storage**: API 呼び出しログを分散型ストレージに保存。従来のクラウドサービスと比較してコストを 95% 削減。
-   **P2P Network**: libp2p をベースに構築された堅牢な中継ネットワーク。
-   **Provider Node**: マルチプラットフォーム対応の軽量クライアント。ワンクリックでクォータの共有が可能。
