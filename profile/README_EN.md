# Token is Token

### Token (LLM) = Token (ERC20)

Token is Token is a decentralized network built on the 0G Chain. It connects global AI resources by turning Large Language Model (LLM) API consumption into on-chain value.

## Vision and Mission

We believe AI intelligence should be a global public good. Our mission is to ensure global accessibility to premium AI resources through a decentralized sharing network. By using blockchain for low-friction settlement, we remove the barriers between model providers and users worldwide.

## Market Opportunity

The global LLM market is growing fast and is expected to exceed $82 billion by 2033. Yet, geographic and financial barriers leave over 11 million users without reliable access to the best models. Token is Token fills this gap by creating a borderless marketplace for AI tokens.

## Core Value Proposition

| Dimension | Traditional Pain Points | Our Solution |
|-----------|-------------------------|--------------|
| **Geographic Limits** | Users in many regions are blocked from accessing models like Claude or GPT-4. | A global P2P network that routes requests through accessible nodes. |
| **Financial Settlement** | Cross-border payments are hard due to currency risks and banking limits. | SHARE tokens provide a unified, borderless settlement unit. |
| **Resource Waste** | Many users have monthly quotas that go unused and expire. | Token incentives reward users for sharing their idle quotas. |
| **Model Silos** | AI markets are fragmented between different regions and providers. | A single platform that integrates the world's best AI models. |

## How It Works

1.  **Providers**: Users with LLM accounts run a provider node to share their idle quotas.
2.  **Consumers**: Users buy SHARE tokens and send API requests through the network.
3.  **Routing**: The P2P network routes requests to the best available provider.
4.  **Settlement**: Smart contracts record usage and settle payments in real-time.

## Token Economics

The network is powered by **ShareToken (SHARE)** on the 0G Chain.

*   **Dynamic Minting**: SHARE is minted based on actual LLM token consumption. The more the network is used, the more value is created.
*   **Distribution**:
    *   **Providers**: 85% (Rewards for sharing API access)
    *   **Protocol Treasury**: 10% (For ecosystem growth and operations)
    *   **Liquidity Incentives**: 5% (For DEX liquidity providers)

## Technical Architecture

*   **0G Chain**: A high-performance L1 with 11,000 TPS and sub-second finality, optimized for AI.
*   **P2P Network**: A decentralized routing layer built for speed and reliability.
*   **Provider Node**: Lightweight software that lets anyone become an AI resource provider.
*   **API Gateway**: A standard interface for easy integration into any application.
